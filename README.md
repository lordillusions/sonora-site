# sonoradaw.com

The website of **Sonora DAW**, a free, open-source music studio. Live at <https://sonoradaw.com>.

Plain static HTML and CSS: no build step, no framework, no external fonts or scripts, no tracking. GitHub Pages serves
this repository as is. Every screenshot is Sonora's own interface.

Look at it locally with `python3 -m http.server 8794`, then open <http://localhost:8794/>. `python3 check_links.py`
fails on a broken local link, image or `#anchor`.
